🎉 Event Booking App — Frontend
This is the frontend of the Event Booking Web Application built using modern web technologies. Users can browse events, book tickets, and admins can manage events through a separate admin panel.



🚀 Features

🌙 Dark mode toggle

🌍 Multi-language support (English / Arabic)
📱 Responsive design

🔐 User authentication (Register/Login)

🏠 Home page with event listings and filter by category

🎟️ Book Now functionality with "Booked" label for booked events

📄 Event Details page with complete info and booking option

🎉 Congratulations page after successful booking

⚙️ Admin panel with full CRUD for events

🧑‍💼 Role-based access (User/Admin)
